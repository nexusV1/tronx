    Tareas con fecha

    Cada tarea de una lista con fecha te avisa ese día a la hora elegida (si todavía no está tildada). Las notas protegidas muestran solo "Nota protegida".

    Acceso rápido

    Deja una notificación fija en la barra: tocala y se abre una nota nueva. Además podés mantener pulsado el ícono de Tronx para crear una nota, una lista o dictar, y agregar el widget de Tronx a tu pantalla de inicio (mantené pulsado un espacio vacío del inicio y elegí Widgets).

    Sonido del agujero negro

    Es el sonido del agujero negro de la pantalla de inicio. Suena solo cuando el agujero negro pasa, y sigue el volumen multimedia del teléfono: si no se escucha, subilo y usá “Probar sonido”. Para silenciarlo, elegí “Silenciado”.

    Copia de seguridad

    Tus notas viven solo en este teléfono. Si desinstalás la app o borrás sus datos, se pierden. Al enviar la copia se abre el menú de Android: elegí Drive, WhatsApp, correo o "Guardar en el teléfono". La copia sin imágenes pesa mucho menos y entra en cualquier chat.

    Plantillas

    Markdown

    Cada nota pasa a un archivo .md (con etiquetas y fechas), ordenado en carpetas. Sirve para abrirlas en otras apps. No incluye las imágenes ni las notas protegidas.

    Copia automática

    Bloqueo con PIN

    Ocultar el título cifra también el nombre de las notas protegidas con PIN o frase: en la lista aparecen como "Nota protegida" hasta que las abrís. Se aplica a una nota la próxima vez que la abras.

    Oculta el contenido de Tronx en la lista de apps recientes. También bloquea las capturas de pantalla.
